# 🎵 FreeFM (Сгенерено нейронкой под валидацией "профессионала")
FreeFM — это проект для динамической подмены треков в Spotify на собственные аудиофайлы (Незацензуренные лейблами РФ). Система состоит из HTTPS-сервера на Rust и клиентского расширения для Spicetify.

🚀 Как это работает
- Rust Server: Раздает локальные .mp3 файлы через защищенное соединение (HTTPS) с поддержкой CORS.
- Spicetify Script: Отслеживает текущий трек в Spotify. Если название совпадает с настроенным списком, он глушит оригинальный поток и воспроизводит файл с вашего сервера, синхронизируя громкость и перемотку.

🛠 Требования
- Rust (для компиляции сервера) и SSL-сертификаты (Let's Encrypt или самоподписанные)
- Spicetify CLI (для модификации клиента Spotify)


📦 Установка и настройка <br>
1. Сервер (Rust)
  - Склонируйте репозиторий;
  - Создайте папку music и положите туда свои треки в формате ключ-значение, где ключом будет выступать endpoint, а значением название трека в папке music;
  - Настройте config.toml:
```toml
music_dir = "./music"
server_addr = "0.0.0.0:3000"

[certs]
cert_path = "fullchain.pem"
key_path = "privkey.pem"
```
2. Клиент (Spicetify)
- Перейдите в директорию расширений Spicetify;
- Перенесите в папку Extensions файл FreeFM.js;
- Отредактируйте SERVER_URL и список myTracks под свои нужды и в соответствии с каталогом сервера.
- Примените изменения:
```console
spicetify config extensions FreeFM.js
spicetify apply
```
